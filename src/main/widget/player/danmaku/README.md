# 弹幕保护计划
B 站实时弹幕池有上限，先进先出，导致大量弹幕艺术尤其是普权弹幕（mode1、4、5、6）以及高级弹幕（mode7）被挤出弹幕池，代码弹幕（mode8）和BAS弹幕（mode9）虽然有专属弹幕池但万一呢……  只好采用笨办法将这些弹幕存档起来以备不时之需。  
- 存档格式：当前为`xml`，待 chrome 支持[Import Bytes](https://tc39.es/proposal-import-bytes)后考虑切换为`seg`（`protobuf`）
- 命名方式：视频cid
